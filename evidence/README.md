# evidence/

Field fixtures generated by Opera Neon Make and served at live public URLs — active fixtures, not a discarded draft. `fixtures/marker.html` is the local unit test; these are the "does it work on a page it didn't co-author, at a URL any browser can reach" check.

| Path | What it is |
|---|---|
| `v2-markers/` | Primary field fixture. 11 markers, hand-verified against its HTML, CSS, and JS. |
| `v2-control/` | Clean control page, no markers. Produced `hidden_share = 0.048` — the project's benign floor. Not broken; load-bearing. |
| `v1-partial/` | First generation, same spec as `v2-markers/`. |
| `fixture.html`, `fixture-v1-evidence.html` | Byte-identical duplicates of `v1-partial/index.html` (see `SHA256SUMS`), captured before `v1-partial/` existed as a directory. Kept for provenance rather than merged away. |

**v1-partial is the interesting one.** Its generator reported six markers created; the page delivered four. The two missing lived in `alt` and `aria-label`. Regenerating from the identical spec produced a complete page. The reliable finding is *inconsistent completeness paired with consistent claims of completion* — not a systematic failure to write attribute-based markers, since the generator clearly can produce them.

`SHA256SUMS` pins down what was actually observed at each URL, since these pages live on infrastructure outside this repo's control and could change or expire.
